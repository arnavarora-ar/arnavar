## Run locally
Serve this directory with a static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Important asset note
The uploaded ZIP did not include the `assets/fall/` and `assets/portal/` frame-image folders expected by the original animation. The animation code has been preserved, but the frame-based cinematic scenes will require those original WebP assets to display fully. The website may otherwise show the layout and text without the complete film sequences.

## Animation preservation
The scroll engine, CSS animation rules, story timeline, 3D type positioning, and interaction logic were not intentionally rewritten. Only portfolio copy, labels, metadata, and contact destinations were customized.
